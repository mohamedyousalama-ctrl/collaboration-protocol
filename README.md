# Collaboration Protocol

This repository is the academic preservation archive for the Collaboration Protocol (CP) research program led by Mohamed Salama.

The archive is being assembled from source artifacts, dated research records, technical specifications, empirical-study materials, implementation evidence, applied-system work, and provenance records. Claims are separated by evidence status so that historical drafts, frozen definitions, later extensions, implementation experiments, and unverified hypotheses are not silently conflated.
