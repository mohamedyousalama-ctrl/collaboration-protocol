sification:  SignalClassification | null
    action_request:         ActionRequest | null
}

SignalClassification {
    clarity:            enum [clear, ambiguous]
    intent_presence:    enum [action_requested, no_action]
    context_fit:        enum [in_scope, out_of_scope]
}

ActionRequest {
    action_id:          string
    action_type:        enum [generate, modify, retrieve, communicate, external]
    description:        string
    intent_id:          string
    context_id:         string
    agent_id:           string | null
}
```

## 2.3 Guardian Outputs

```
GuardianDecision {
    decision:           enum [Allow, Clarify, Refuse]
    reason:             string
    friction_trigger:   FrictionTrigger | null
}

FrictionTrigger {
    trigger_type:       enum [ambiguous_signal, unverified_intent, scope_boundary,
                              permission_violation, high_risk_action, missing_context,
                              conflict_detected]
    trigger_description: string
}
```

## 2.4 Post-Classification Rules (Checkpoint 1)

| Rule | Condition | Decision | Friction |
|------|-----------|----------|----------|
| PC-1 | `clarity == ambiguous` | Clarify | `ambiguous_signal` |
| PC-2 | `context_fit == out_of_scope` | Clarify | `scope_boundary` |
| PC-3 | `clarity == clear` AND `intent_presence == no_action` | Allow | null |
| PC-4 | `clarity == clear` AND `intent_presence == action_requested` | Allow | null |

**Evaluation order:** PC-1 → PC-2 → PC-3 → PC-4 (first match wins)

---

## 2.5 Pre-Execution Rules (Checkpoint 2)

| Rule | Condition | Decision | Friction |
|------|-----------|----------|----------|
| PE-1 | Intent does not exist | Refuse | `unverified_intent` |
| PE-2 | `intent.state` NOT IN [verified, active] | Refuse | `unverified_intent` |
| PE-3 | `action.context_id` ≠ `intent.context_id` | Refuse | `scope_boundary` |
| PE-4 | `context.state` ≠ open | Refuse | `scope_boundary` |
| PE-5 | Agent not in `context.allowed_agents` | Refuse | `permission_violation` |
| PE-6 | `agent.state` ≠ active | Refuse | `permission_violation` |
| PE-7 | Advisory agent + restricted action | Refuse | `permission_violation` |
| PE-8 | Explanation-only agent + non-communicate | Refuse | `permission_violation` |
| PE-9 | `action_type == external` | Clarify | `high_risk_action` |
| PE-10 | Active unresolved friction exists | Refuse | `conflict_detected` |
| PE-11 | All checks pass | Allow | null |

**Evaluation order:** PE-1 → PE-11 (first match wins)

---

## 2.6 Guardian Constraints

| Constraint | Enforcement |
|------------|-------------|
| No internal state | No fields persisted between invocations |
| Cannot write to stores | No write operations |
| Cannot create objects | Returns trigger; Friction Manager creates |
| Cannot modify objects | All access is read-only |
| Decisions logged by caller | Guardian does not write to LogStore |
| Cannot skip rules | Evaluation order is fixed |
