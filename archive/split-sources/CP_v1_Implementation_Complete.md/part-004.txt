## 6.2 Component Inventory

| Component | Layer | Responsibility |
|-----------|-------|----------------|
| **Signal Receiver** | Interface | Captures user input as raw signal |
| **Response Emitter** | Interface | Delivers system responses |
| **Signal Classifier** | Protocol | Classifies clarity, intent, context fit |
| **CP Guardian** | Protocol | Evaluates constraints, issues gate decisions |
| **Friction Manager** | Protocol | Creates and tracks FrictionEvents |
| **Intent Processor** | Execution | Constructs and manages Intent lifecycle |
| **Agent Dispatcher** | Execution | Routes verified intents to agents |
| **Action Executor** | Execution | Executes allowed actions |
| **Context Store** | State | Persists Context objects |
| **Intent Store** | State | Persists Intent objects |
| **Node Store** | State | Persists Node and Pivot objects |
| **Action Store** | State | Persists Action records |
| **Log Store** | State | Append-only event log |

## 6.4 Guardian Placement

**Checkpoint 1 — Post-Classification**
- Location: Between Signal Classifier and Execution Layer
- Function: Determines routing based on classification

**Checkpoint 2 — Pre-Execution**
- Location: Between Action Executor and actual execution
- Function: Final gate decision before action takes effect

---

## 6.5 State Boundaries

| Store | Owns | Cannot Access Directly |
|-------|------|------------------------|
| Context Store | Context objects | Intent, Node, Action data |
| Intent Store | Intent objects | Node, Action data |
| Node Store | Node, Pivot objects | Intent, Action data |
| Action Store | Action objects | Context, Intent definitions |
| Log Store | All event logs | Cannot modify any object |

---

## 6.6 Architecture Constraints

| Constraint | Rationale |
|------------|-----------|
| Guardian has no write access | Cannot modify what it evaluates |
| All writes generate log entries | Ensures reconstructibility |
| Stores accessed by ID only | Maintains state boundaries |
| Friction Manager cannot auto-resolve | User must resolve |
| Log Store is append-only | Prevents tampering |
