### 6.4 IFI Badge
- Appears below every response
- Shows "IFI –.–" (pending) until SS submitted
- Updates to "IFI 0.84" after star rating
- Color: green ≥ 0.80 / amber 0.60–0.79 / red < 0.60
- Star rating (1–5) alongside badge — optional, encouraged

### 6.5 Pivot Trace Panel
- "Trace" button on every response
- Opens inline panel:
  - Intent and context governing this response
  - ICD level applied
  - IPPs detected (including those below threshold — not surfaced)
  - Guardian Checkpoint 1 and 2 decisions and reasons
  - Safety Floor applied (if any)
  - Decay score at time of response
  - IFI breakdown (SA, CP, SS, composite)
- All plain language — no UUIDs or technical codes visible

### 6.6 Counterfactual Panel
- "What if I meant something else?" button appears on a response when:
  - At least one IPP was detected during classification, AND
  - That IPP was not surfaced as friction (was below ICD threshold)
- Shows 2–3 alternative interpretations with their IPP type
- User selects one → Klear regenerates the response with that interpretation
- Both original and alternative response visible in thread for comparison

### 6.7 Safety Floor Card
- Appended below responses when domain is health / legal / financial
- Distinct teal/blue border treatment
- Domain-appropriate text (health vs legal vs financial)
- Version stamp visible
- Non-dismissible

### 6.8 Session Health Indicator
- In CP Status bar
- Three states: Good (green) / Drifting (amber) / High drift (red)
- Tooltip: "This shows how closely your conversation matches your declared goal"
- Automatically triggers decay friction card when state turns red

### 6.9 Audit Trail Panel
- Collapsible side panel
- Shows CP log events and Klear extension events in chronological order
- Human-readable labels — no raw event codes visible to user
- "Export Compliance Report" button (registered users only)

### 6.10 Auth Flow
- Anonymous session starts immediately — no gate
- "Save your session" prompt after 3rd message
- Email magic link via Supabase Auth
- Anonymous session migrates to authenticated account
- Registered users see: session history, IFI trends, Context Roots, Klear Profiles

### 6.11 Klear Profile Manager (Registered Users)
- Create / edit / delete named profiles
- Each profile: ICD default, context template, constraint list, domain preference
- Load profile at session start — pre-fills articulation card
- "Save to profile" button on active nodes → triggers Context Root save
