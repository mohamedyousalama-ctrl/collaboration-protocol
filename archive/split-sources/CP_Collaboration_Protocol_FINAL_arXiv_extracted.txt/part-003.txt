4.1.5 Semantic Materiality Proxy
A critical challenge is determining which ambiguities are materialsignicant enough to warrant
user attentionversus trivial variations that can be resolved autonomously. Rather than relying
solely on subjective human judgment, we propose a Semantic Materiality Proxy (SMP) that
quanties materiality through measurable properties.
Denition. For an ambiguous element a with possible interpretations {i1, i2, ..., in}, the Materiality Score is:
M(a) = [α · Dsem + β · Cmag + γ · (1 − R)] × CF(a) (2)
where:
 Dsem = 1 − maxi,j cos(ei, ej ) is the semantic distancehow dierent the interpretations are in
embedding space
 Cmag ∈ [0, 1] is the consequence magnitudeestimated impact based on task type (e.g.,
nancial transactions → high, casual chat → low)
 R ∈ [0, 1] is the reversibilityhow easily the decision can be undone (permanent deletion → 0,
rephrasing text → 1)
 α + β + γ = 1 are domain-calibrated weights (default: α = 0.4, β = 0.4, γ = 0.2)
 CF(a) ∈ [0.5, 1.5] is the Context Factor from Equation 1how prior context aects ambiguity
Materiality Classication. An ambiguity is classied as:
 Critical if M(a) ≥ 0.7 or Cmag ≥ 0.9
 Signicant if 0.4 ≤ M(a) < 0.7
 Minor if M(a) < 0.4
Rationale. This composite approach addresses the limitation of pure semantic distance: two
interpretations may be semantically close yet have vastly dierent consequences. For example,
delete temp les vs. delete all les have high cosine similarity (∼0.85) but dramatically dierent
consequences (Cmag = 0.95, R = 0.1), yielding M ≈ 0.68correctly classied as Signicant.
Threshold Calibration. The default weights and thresholds represent initial estimates requiring empirical calibration. Domain-specic deployments (legal, medical, nancial) may adjust
weights to prioritize consequence magnitude over semantic distance. The key contribution is providing an objective, measurable foundation for materialitytransforming a subjective judgment into a
computable function.
