## APPENDIX B: TERMINOLOGY DEFINITIONS

| Term | Definition |
|------|------------|
| **Context** | Bounded, user-declared semantic and operational scope within which reasoning and actions are permitted |
| **Intent** | Explicit, verified declaration of what the user wants the system to do, under defined constraints, before execution |
| **Agent** | Scoped executor or advisor that operates within a context under explicit permissions |
| **Node** | User-committed structural constraint that governs future reasoning |
| **Pivot** | User-declared epistemic marker indicating perceived importance without implying intent or commitment |
| **Guardian** | Read-only evaluation component that issues gate decisions at critical checkpoints |
| **Friction** | Deliberate pause at critical decision points when ambiguity, risk, or missing verification is detected |
| **Gate Decision** | One of exactly three outcomes: Allow, Clarify, or Refuse |
| **Responsibility Chain** | Unbroken path from user signal to system action, logged at every link |
| **Verification** | Explicit user confirmation; words alone do not constitute intent |
