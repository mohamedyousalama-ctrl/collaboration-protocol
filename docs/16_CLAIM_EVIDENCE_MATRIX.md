## Required language discipline

Prefer:

- “the specification defines…”
- “the recovered implementation contains…”
- “the pilot workbooks report…”
- “the current archive does not establish…”
- “we propose/hypothesize…”
- “this will be tested against…”

Avoid unless the relevant evidence gate is actually closed:

- “proven”
- “validated”
- “guarantees safety”
- “first ever”
- “novel worldwide”
- “beats competitors”
- “production-ready”
- “clinically safe”
- “patented” when only a draft/provisional claim is available

The repository is intended to make stronger claims possible later by keeping the present evidentiary boundary explicit now.
